## 本次更新
- 分应用代理：可选「代理名单」（仅勾选的应用走隧道）或「直连名单」（勾选的应用绕过隧道）；Android 与 Windows 均支持。修改后需重新连接才生效，应用内已有提示。
- 全节点连接提速（连接握手不再等待旧版流程）。
- 设置内语言切换：跟随系统 / 中文 / English。
- 修复 IPv6 泄漏——双栈网站不再绕过隧道。
- Windows：吞吐大幅提升，状态栏新增实时上传 / 下载速度显示。
- 连接 / 断开更稳定，修复偶发卡在「连接中」的问题。

## What's new
- Per-app proxy: choose a proxy list (only selected apps use the tunnel) or a direct list (selected apps bypass it); available on Android and Windows. Changes take effect after reconnecting — the app shows a reminder.
- Faster connections across all nodes (the connect handshake no longer waits on the legacy setup step).
- Language switch in Settings: Follow system / 中文 / English.
- IPv6 leak fixed — dual-stack sites no longer bypass the tunnel.
- Windows: much better throughput, plus live upload/download speed in the status bar.
- More reliable connect/disconnect, fixing the occasional stuck "connecting" state.

### Install
**Android**: download the APK and install (allow unknown sources)
**Windows**: download the ZIP, extract and run mirrorspeed_vpn.exe (first launch: right-click → Run as administrator)
