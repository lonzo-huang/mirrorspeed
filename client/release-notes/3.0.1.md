## 本次更新
- 修复：分应用代理（代理名单 / 直连名单）现在**仅在「智能模式」下生效**。「全局模式」会忽略名单，所有流量都走 VPN。
- 分应用代理页新增提示：处于全局模式时会说明名单暂不生效，切换到「智能模式」后才会生效。

### 安装
**Android**：下载 APK 安装（需允许「未知来源」）
**Windows**：下载 ZIP 解压后运行 mirrorspeed_vpn.exe（首次右键 → 以管理员身份运行）

## What's new
- Fix: the per-app proxy (proxy list / direct list) now applies **only in Smart mode**. Global mode ignores the list and routes all traffic through the VPN.
- The per-app screen now shows a notice while you're in Global mode, explaining the list is inactive until you switch to Smart mode.

### Install
**Android**: download the APK and install (allow unknown sources)
**Windows**: download the ZIP, extract and run mirrorspeed_vpn.exe (first launch: right-click → Run as administrator)
